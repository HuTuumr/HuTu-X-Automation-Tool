评论规则（可改）

这份规则存在当前这台电脑的浏览器里，两台电脑可以各用各的。

用法

装上后打开 x.com，每条推文下面会出现一个 AI 按钮。点它 → 右侧面板显示原帖和草稿，不满意可「重新生成」，满意点「回复」自动发出去。

怎么跑起来

  1. 打开 LM Studio → 左侧 Model Server → 点 Start Server，确认端口 1234。
  2. 在 Chat 里加载 Qwen3-4B。
  3. 回到这里点「测试连接」，模型下拉框出现名字后点「保存」。
  4. 打开 x.com，点推文下面的 AI 按钮。
接口连不上时：确认 LM Studio 里 CORS 已允许（lms server start --cors 或设置里打开），并确认端口与上面一致。
